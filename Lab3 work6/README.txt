ASP.NET Web.config Tags Demonstration

Files:
1. Web.config
2. Default.aspx
3. Default.aspx.cs

How to use:
- Create an ASP.NET Web Forms project named WebConfigDemo.
- Replace/add these files in the project.
- Make sure the project targets .NET Framework 4.8 (or adjust targetFramework).
- Run Default.aspx.

Important:
If your project namespace is different, change "WebConfigDemo" in Default.aspx and Default.aspx.cs.
The connection string is only a demonstration; change it according to your SQL Server/database.
