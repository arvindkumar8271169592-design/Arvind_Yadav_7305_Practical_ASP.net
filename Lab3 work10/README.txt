Calculator Webpage - Exception Handling
=========================================

Files:
1. Calculator.aspx
2. Calculator.aspx.cs

How to use:
- Create an ASP.NET Web Forms project named Calculator in Visual Studio.
- Add a Web Form named Calculator.aspx.
- Replace its code with the provided Calculator.aspx code.
- Replace Calculator.aspx.cs with the provided C# code.
- Run the project.

Exception handling:
- FormatException: invalid number input.
- DivideByZeroException: division by zero.
- General Exception: other input/errors.
- finally: executes after division operation.
